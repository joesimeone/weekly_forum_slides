# Things I Wish Someone Had Told Me About Git

Slides for a talk covering Git fundamentals (commits, branches, forks), squash & merge workflows, and worktrees for agentic AI.

Built with [Quarto](https://quarto.org/) and [Reveal.js](https://revealjs.com/), using Grant McDermott's [clean theme](https://github.com/grantmcdermott/quarto-revealjs-clean) as a style reference.

## Render

```bash
quarto render git_in_a_nutshell.qmd
```
